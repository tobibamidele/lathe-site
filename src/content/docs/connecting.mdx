lathe talks to `database/sql` and never imports a driver itself. You import the driver you want for its side effect, then open a connection with the matching lathe package. The result is a `*lathe.DB`, which the generated `NewClient` wraps.

## Open a connection

<Tabs labels={['PostgreSQL', 'MySQL', 'SQLite']}>
<Tab>

```go
import (
    _ "github.com/jackc/pgx/v5/stdlib" // or _ "github.com/lib/pq"

    "github.com/tobibamidele/lathe/postgres"
    "myapp/db"
)

conn, err := postgres.Open("postgres://user:pass@localhost:5432/app?sslmode=disable")
if err != nil {
    log.Fatal(err)
}
defer conn.Close()

client := db.NewClient(conn)
```

</Tab>
<Tab>

```go
import (
    _ "github.com/go-sql-driver/mysql"

    "github.com/tobibamidele/lathe/mysql"
    "myapp/db"
)

// go-sql-driver DSN, or a mysql:// URL
conn, err := mysql.Open("user:pass@tcp(localhost:3306)/app")
if err != nil {
    log.Fatal(err)
}
defer conn.Close()

client := db.NewClient(conn)
```

</Tab>
<Tab>

```go
import (
    _ "modernc.org/sqlite" // or _ "github.com/mattn/go-sqlite3"

    "github.com/tobibamidele/lathe/sqlite"
    "myapp/db"
)

conn, err := sqlite.Open("app.db") // a path, a file: URI or ":memory:"
if err != nil {
    log.Fatal(err)
}
defer conn.Close()

client := db.NewClient(conn)
```

</Tab>
</Tabs>

`Open` does not dial, just like `sql.Open`. Check the connection when you want to fail fast:

```go
ctx, cancel := context.WithTimeout(context.Background(), 5*time.Second)
defer cancel()
if err := conn.Ping(ctx); err != nil {
    log.Fatalf("cannot reach the database: %v", err)
}
```

## What Open sets up for you

| Database | Options added |
| --- | --- |
| PostgreSQL | none; the DSN is passed to the driver as is |
| MySQL | `parseTime=true` and `clientFoundRows=true`, unless you set them. A `mysql://` URL is converted to a driver DSN. |
| SQLite | `foreign_keys` on, a 5 second busy timeout and WAL for file databases, on every connection. `:memory:` uses a single connection. |

<Callout title="Building the *sql.DB yourself?">
Pass it to `postgres.New(db)`, `mysql.New(db)` or `sqlite.New(db)`. You then own the settings above. Without `parseTime`, MySQL timestamps cannot scan into `time.Time`, and SQLite only enforces foreign keys when the pragma is set on every connection.
</Callout>

## Connection pool

`conn.SQL()` returns the underlying `*sql.DB`, so the standard pool settings apply:

```go
sqlDB := conn.SQL()
sqlDB.SetMaxOpenConns(20)
sqlDB.SetMaxIdleConns(10)
sqlDB.SetConnMaxLifetime(30 * time.Minute)
```

## Read the URL from the environment

```go
conn, err := postgres.Open(os.Getenv("DATABASE_URL"))
```

The CLI reads the same variable: `lathe migrate up` uses `--url` or `$DATABASE_URL`.

## No driver registered

If you forget the driver import, `Open` says which one to add:

```text
lathe/postgres: no database/sql driver is registered (looked for pgx, postgres);
import one, for example: _ "github.com/jackc/pgx/v5/stdlib"
```
